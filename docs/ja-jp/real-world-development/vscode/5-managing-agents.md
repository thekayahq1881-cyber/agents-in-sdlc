GitHub Copilot をエージェント モードで使うと、コードベースを調べ、変更を提案し、ファイルを編集し、コマンドを実行するなど、自律的に作業します。VS Code の Copilot Chat はマシン上でリアルタイムに実行される作業を表示します。ツールの呼び出しやファイルの編集を逐一確認できます。差分をインラインでレビューし、個々の変更を適用または取り消し、エディターを離れずに追加のプロンプトを送信して作業の調整や拡張を依頼できます。

この演習では、次のことを行います。

- アクセシビリティ エージェントの作業をリアルタイムで監視します。
- 提案されたファイルの編集をレビューし、適用します。
- セッション中にエージェントへ指示を追加し、ハイ コントラストに加えてライト モードの切り替えを追加します。

## シナリオ

[演習 4][previous-lesson]で使ったアクセシビリティ カスタム エージェントは、ハイ コントラスト モードを実装しています。作業中にデザイン チームから追加の依頼がありました。既定のテーマが暗すぎると感じるユーザー向けに、ライト モードの切り替えも追加したいとのことです。新しい会話を最初から始めずに、既存のセッションに指示を追加して作業を拡張します。

## Copilot の進行状況を監視する

Copilot Chat ビューには、エージェントが実行する手順 (調べたファイル、実行したコマンド、提案した編集) が表示されます。ファイルの編集は差分と **Keep** / **Undo** の操作とともにチャット内に表示されます。

1. 演習 4 で使った Copilot Chat ビューに戻ります。
2. エージェントの作業中にチャットをスクロールし、各ツールの呼び出しを確認します。ファイルの読み取りや編集、実行を求められたターミナル コマンドが表示されます。
3. エージェントがファイルの編集を提案すると、差分がインラインで表示されます。
   - **Keep** を選択すると変更を適用します。
   - **Undo** を選択すると変更を取り消し、エージェントにもう一度試してもらいます。
4. チャット上部の **Files changed** を開き、セッション中にエージェントが変更したすべてのファイルを確認することもできます。

> [!NOTE]
> ターミナル コマンドの実行などでツールの許可が必要な場合、エージェントは一時停止して **Allow** を求めます。内容を確認し、実行を許可できるコマンドだけを承認してください。

5. エージェントがハイ コントラスト モードを実装し終えるまで待ちます。最後に、変更内容の要約が表示されます。

## エージェントにライト モードを追加するよう指示する

ハイ コントラスト モードができたので、同じ会話でライト モードの切り替えも追加します。同じチャット セッションを続けるため、エージェントは前の作業のコンテキスト (変更したコンポーネント、スタイルの方針、設定した local storage のパターンなど) を保持しています。

1. Copilot Chat の入力欄に次の追加プロンプトを送信します。

   ```plaintext
   Nice work! Now add a light-mode toggle alongside the high-contrast toggle. Light mode should follow the same pattern — persist via local storage and be accessible from the same area of the UI. The user should be able to enable high-contrast and light mode independently.
   ```

2. エージェントは既存の変更を調べ、新しいライト モードの追加を提案します。
3. ハイ コントラスト モードのときと同じように、新しい編集を確認します。差分ごとに **Keep** または **Undo** を選択します。
4. エージェントが望まない方向に進んだ場合 (たとえば、好みと異なる方法で切り替え UI をリファクタリングする場合) は、チャット入力欄の横にある **Stop** ボタンで停止し、補足するプロンプトを送信します。

> [!TIP]
> 進行中のセッションに指示を加えると、最初からやり直すより短時間で修正できます。追加のプロンプトで調整を依頼できます (例: 「CSS を簡潔にして、セレクターの重複ではなく CSS 変数を使う」)、方針を修正できます (例: 「3 つ目の切り替えを追加せず、ライト モードを既存の設定パネルに統合する」)、範囲を広げることもできます (例: 「両方の切り替えにキーボード ショートカットも追加する」)。

## 作業内容をレビューする

作業をコミットする前に、エージェントが変更したすべての内容を確認します。

1. VS Code で **Source Control** ビューを開きます。
2. 変更されたファイルの一覧を確認します。Astro コンポーネント、スタイル、関連テストなどが更新されているはずです。
3. 変更されたファイルをいくつか開き、差分を確認します。カスタム エージェントが示したアクセシビリティの方針 (ARIA 属性、キーボード操作、セマンティック HTML、local storage による設定の保持など) が反映されていることを確認します。
4. 問題がなければ、Source Control パネルから変更をステージしてコミットします。次のレッスンで公開します。

## まとめと次のステップ

Copilot Chat のエージェント モードを使って、進行中のセッションを監視し、指示を追加しました。ファイルの編集を確認し、変更を適用または取り消し、コンテキストを保ったまま追加のプロンプトを送って作業を拡張しました。

このレッスンでは、次のことを行いました。

- エージェントの作業をリアルタイムで監視しました。
- 個々のファイル編集を適用または取り消しました。
- セッション中に追加のプロンプトを送ってエージェントに指示しました。
