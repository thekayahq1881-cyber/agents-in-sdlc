**[GitHub Copilot app][about-copilot-app]** は、エージェント主導の開発に使うデスクトップ アプリケーションです。GitHub Copilot CLI を基盤とし、GitHub とネイティブに統合されているため、リポジトリ、ブランチ、CI パイプラインをすぐに利用できます。自分だけで作業するのではなく、それぞれ独立したワークスペースで複数のエージェントに並行して作業を指示し、繰り返し作業を自動化するワークフロー向けに設計されています。Node.js のインストールとプロジェクトの準備ができたので、次はアプリをインストールしてリポジトリを接続します。

このレッスンでは、次のことを行います。

- GitHub Copilot app をインストールしてサインインします。
- GitHub リポジトリからプロジェクトをアプリに追加します。
- テンプレートで準備されたバックログなど、ワークスペースを確認します。
- クイックチャットを試して、アプリについて質問します。

## シナリオ

チームでは、増え続けるバックログに対応するために AI エージェントを使い始めています。Copilot app では、issue の取得、エージェントの実行、変更のレビュー、プルリクエストのマージなどを、一か所から指示できます。このレッスンでは、アプリをインストールして接続し、プロジェクトについての会話を始められるようにします。

> [!NOTE]
> 対象となる Copilot プランが必要です。Copilot Free、Copilot Student、または有料プラン (Pro、Pro+、Business、Enterprise) を利用してください。Copilot Business または Copilot Enterprise では、管理者が **GitHub Copilot app** ポリシーを有効にしておく必要があります。

## GitHub Copilot app をインストールして構成する

GitHub Copilot app を使用するには、まずアプリをインストールします。Windows、macOS、Linux 向けのバージョンが用意されています。アプリをインストールして認証し、Tailspin Toys リポジトリを追加しましょう。

1. ブラウザーで [GitHub Copilot app のランディング ページ][download-app]を開きます。
2. 使用しているプラットフォーム向けのアプリをダウンロードし、ランディング ページの手順に従ってインストールします。
3. インストール後、アプリを開きます。
4. **Sign in to GitHub** を選択し、画面の案内に従って認証します。データ所在地に対応する GitHub Enterprise Cloud を使う場合は、**Use GitHub Enterprise** を選択し、求められたら `*.ghe.com` のホスト名を入力します。GitHub Enterprise Server はサポートされていません。
5. オンボーディングでリポジトリを選択する画面が表示されたら、テンプレートから作成した Tailspin Toys リポジトリを選択します。リポジトリ選択をスキップし、オンボーディング後にプロジェクトを追加することもできます。
6. テーマを選択するよう求められたら選択し、オンボーディングを完了します。
7. サイドバーの **Sessions** でリポジトリを探します。すでに表示されている場合は、もう一度追加する必要はありません。
8. まだ接続されていない場合は、**Sessions** の横にある **+** を選択して新しいセッションを作成し、**Add GitHub repository** を選択します。前提条件のレッスンで控えた所有者名とリポジトリ名を入力します。
9. リポジトリがサイドバーに表示されていることを確認します。ここで使うレイアウトでは、`tailspin-toys` などのリポジトリ フォルダーが **Sessions** の下にまとめられ、その下に個々のセッションが表示されます。

## ワークスペースを確認する

プロジェクトを接続したら、アプリの使い方を確認しましょう。サイドバーには、主に次の領域があります。

- **New** — 新しいチャット セッションを開始します。
- **Pull requests** — アプリの GitHub ネイティブ統合を通じてプルリクエストを表示します。アプリを離れずに、プルリクエストの参照や絞り込み、CI 状態の確認、レビューを行えます。
- **Issues** — GitHub issue を表示します。issue の参照や絞り込み、issue からのセッション開始を行えます。
- **Automations** — スケジュールまたはオンデマンドで実行する、保存済みのエージェント タスクです。ToDo リストの管理、定期的なプロジェクト保守、その他の面倒な作業を任せるのに役立ちます。振り返りでは次のステップとして紹介します。別のワークショップ演習ではありません。
- **Customize** — MCP サーバー、プラグイン、スキル、その他のコンポーネントを使って Copilot app に機能を追加します。Playwright MCP の構成に使用します。
- **Chats** — ブランチや専用ワークスペースを必要としない、質問やブレインストーミング向けの簡易的な会話です。最初のチャットを開始すると、このセクションが表示されます。表示されない場合は、**Sessions** の横にある **+** を選択して最初のチャットを開始します。
- **Sessions** — リポジトリ フォルダーと、その中のエージェント セッションをまとめます。リポジトリ名 (例: `tailspin-toys`) を選択するとリポジトリ ビューが開き、その下のセッションを選択すると会話に戻ります。セッションごとに独立したワークスペースが用意されるため、変更が競合することなく複数のセッションを同時に実行できます。最初のセッションは星評価を追加するときに開始します。

ワークショップを進めながら、ワークスペースの各機能を確認していきます。

> [!TIP]
> 迷ったときは Copilot に質問しましょう。操作方法がわからない場合や、何かが可能かどうか知りたい場合は、Copilot が案内してくれます。

### 準備されたバックログを確認する

バックログのないプロジェクトはほとんどなく、Tailspin Toys も例外ではありません。テンプレートからリポジトリを作成したときに準備されたバックログを確認します。

1. サイドバーの **Sessions** で、個々のセッションではなく Tailspin Toys のリポジトリ フォルダーを選択します。リポジトリの上部ナビゲーションで **Issues** を選択します。
2. issue 番号を決めつけず、次のタイトルを探します。
   - Allow users to filter games by category and publisher
   - Update our repository coding standards
3. issue を選択して詳細を読みます。各 issue からエージェント セッションを開始できます。最初の小さな変更を完了してから、絞り込み issue に取り組みます。

> [!NOTE]
> **Issues** と **Pull requests** の一覧には、Copilot app に追加したリポジトリの項目だけが自動的に表示されます。ほかのリポジトリの作業項目を表示するには、そのリポジトリもアプリに追加してください。

## クイックチャットを試す

アプリに慣れるには、*アプリ自体*について質問するのが効果的です。その用途には**クイックチャット**が適しています。クイックチャットでは、ブランチや worktree を作成せずに質問やブレインストーミングができます。セッションを必要としない、短時間で終わる質問に最適です。

1. サイドバーの **Chats** の横にある **+** を選択して、新しいチャットを開きます。**Chats** がまだ表示されていない場合は、**Sessions** の横にある **+** を選択して最初のチャットを開始します。開始後に **Chats** が表示されます。
2. アプリのセッションについて質問します。

   ```plaintext
   How does the GitHub Copilot app use worktrees?
   ```

3. 会話ビューで応答を読みます。各セッションが独立した Git worktree で実行されるため、変更が競合することなく複数のエージェントを並行して実行できることがわかります。会話はいつでも続けられ、新しいチャットも開始できます。

## まとめと次のステップ

GitHub Copilot app をインストールし、プロジェクトを接続して、ワークスペースを確認しました。次のことを学びました。

- アプリをインストールして GitHub にサインインする。
- GitHub リポジトリからプロジェクトを追加する。
- ワークスペースを確認し、**Issues** で準備されたバックログを見つける。
- クイックチャットを使って、その場限りの質問をする。

次は、最初のエージェント セッションを開始し、ゲーム カードに星評価を表示します。
